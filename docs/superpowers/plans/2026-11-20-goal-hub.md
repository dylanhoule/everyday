# Goal Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn everyday from a flat todo list into a goal hub: goals with habits, phases and measures that fill each day, scored into day scores, streaks, and a heatmap, in the dark design from `everyday-selection.pdf`.

**Architecture:** All data stays one synced array of records (`goal`, `habit`, `task`, `log`) merged per record by `src/merge.js`. Pure modules compute everything derived (`src/score.js` for days and streaks, `src/goals.js` for per-goal numbers and copy) and every mutation (`src/actions.js`), all tested with `node:assert`. React components only render those results; `App.jsx` owns state, sync, and navigation.

**Tech Stack:** React 19, Vite 8, `motion`, `vite-plugin-pwa`, Vercel serverless (`api/todos.js`) + Upstash Redis. No new runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-11-20-goal-hub-design.md` (read it before any task). Visual reference: `everyday-selection.pdf` (p1 desktop Today, p2 phone Today, p3 phone Goals, p4 Goal detail, p5 Progress).

## Global Constraints

- No em dashes anywhere: UI copy, comments, commit messages, docs. Use commas, colons, periods, parentheses.
- No new runtime dependencies. Fonts load from Google Fonts in `index.html`.
- Dates are local `YYYY-MM-DD` strings built with `src/date.js`; never `toISOString()` for a day.
- Every record carries `id`, `type`, `updatedAt` (ms); deletes are tombstones (`deleted: true`). `merge.js`, `purge`, `api/todos.js`, and the Redis key are unchanged.
- Weekday numbers are JS `getDay()`: 0 = Sun ... 6 = Sat. Weeks display Mon to Sun.
- A day is **open** if it is today or yesterday; anything older is **locked** (no log created, removed, or re-amounted).
- Tests are plain `node:assert` scripts listed in the `npm test` script, each ending with a `console.log('<file>: all assertions passed')`.
- Work on branch `goal-hub`; commit after each task; never push (the user pushes to deploy).

## Review Focus

1. **Midnight while the app is open or backgrounded:** on focus/visibility the app must recompute `today`, so yesterday's leftovers move to Earlier and the score resets. (Manual check in Task 7.)
2. **The same habit checked on phone and laptop:** must end as one log, not two. (Test in Task 4.)
3. **Malformed or legacy records in the synced blob** (no `id`, `null`, old `text`-only todos): must load without crashing. (Test in Task 1.)
4. **Today outside every path phase** (gaps, before the first, after the last): no current phase, measure falls back to `measure.target`. (Test in Task 3.)
5. **Date math across DST changes:** day counts and countdowns must not drift by one. (Test in Task 1.)

## Record shapes (from the spec; every task uses these names)

```js
// goal
{ id, type: 'goal', name, title, color /* 'orange'|'blue'|'cyan'|'purple'|'green'|'pink' */,
  date?, endDate?, note?, measure?: { unit, target, per: 'week'|'total' },
  stat?: { value, label }, path: [{ name, start, end, note?, target? }],
  createdAt, archivedOn?, updatedAt, deleted? }
// habit
{ id, type: 'habit', goalId, title, note?, time? /* 'HH:MM' */, days: number[],
  amount?, unit?, startDate, endDate?, updatedAt, deleted? }
// task
{ id, type: 'task', goalId?, title, note?, date, time?, amount?, unit?, done, doneDate?, updatedAt, deleted? }
// log
{ id: `log:${habitId}:${date}`, type: 'log', habitId, date, amount, unit?, updatedAt, deleted? }
```

`Item` (what lists render), produced by `itemsOn`:
`{ kind: 'habit'|'task', id, date, title, note, time, goal /* goal record or null */, done, amount, unit, rec /* the habit or task */ }`

**Interfaces:**

- Produces:
  - `index(records) -> Idx` where `Idx = { goals: goal[] (live, incl. archived, sorted by createdAt then id), goalById: Map, habits: habit[], tasks: task[], logs: Map<logId, log> }`, built from non-deleted records only.

  - `streaks(idx, today) -> { current: number, best: { len, start, end } | null }`.

  - `rangeAverage(idx, today, n) -> { avg: number|null, prev: number|null }`.

import { index, habitDueOn, itemsOn, dayScore, isLocked, toKeep, historyStart, streaks, dayCell, rangeAverage } from './score.js';

import { addDays } from './date.js';

assert.equal(habitDueOn(run, goal, '2026-11-18'), false);                       // Wednesday not in days

assert.equal(habitDueOn(run, { ...goal, archivedOn: T }, T), false);            // archived from that day
assert.equal(habitDueOn(run, { ...goal, archivedOn: T }, '2026-11-17'), true);  // past days keep counting
assert.equal(habitDueOn(run, { ...goal, date: '2026-11-18' }, T), false);       // after the goal's last day
assert.equal(habitDueOn(run, { ...goal, date: '2026-11-10', endDate: '2026-11-20' }, T), true);

- [ ] **Step 3: Implement `src/score.js`**

Rules not determined by the tests:
- `habitDueOn`: due iff `date >= startDate`, `!endDate || date <= endDate`, `days.includes(weekday(date))`, `!goal.archivedOn || date < goal.archivedOn`, `!lastDay(goal) || date <= lastDay(goal)`. Habits whose goal is missing from the index are never due.
- Task done for its date iff `done && doneDate && doneDate <= addDays(date, 1)`.
- `streaks`: walk every day from `historyStart` to `today`. Rest day: skip. Score >= 70: run += 1 (record start date when run begins). Score < 70 and not locked: skip. Score < 70 and locked: close the run (update best), run = 0. `current` = run at the end; `best` = longest run seen including the final one, `null` when no run ever reached 1. Ties keep the earlier run.
- `dayCell`: `none` if no history start, `date < historyStart`, or `date > today`.
- `rangeAverage`: days `today-n .. today-1` and `today-2n .. today-n-1`, skipping `null` scores and days before history; mean rounded; `null` if no scored days.
